### 不补造医学内容

参考区间照录原字段。原文没有对应解释时不生成新解释；现有临床意义作为对应判读内容保留。通用教学条目没有方法、人群明确的数值时明确留缺，不把其他机构或同名方法的范围移植过来。

原名中的 `▲`、原文短横线、空白和“同上”均保留；截图中的黑色三角不是UI错误，不因视觉审查而删除医学标记。机构适用范围和未医学审核状态仍能看见，但不再重复堆叠说明卡片。
