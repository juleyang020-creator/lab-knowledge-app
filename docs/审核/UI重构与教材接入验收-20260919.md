## 决策与取舍记录

- **行链接可访问名**：初版整行 RouterLink 使链接名为整行文本，e2e 与读屏均不可用；改为项目名链接 + `.item-name::after` stretched-link，整行可点且链接名干净。
- **WebKit select**：默认 appearance 下 WebKit 忽略 select 的 padding/min-height（lab-manual-import 已有选项文字越界记录），`appearance:none` + 自定义箭头后触控目标达标。
- **行锚点不含标题行**：教材同名条目指向标题行时无锚点可落；阅读器改为高亮其后最近正文块。
- **SourcesView 重试双拉**：目录置空触发外壳卸载重挂载，造成 patient.json 重复拉取；三文件 QA 移入 workspace（`loadSourcesQA`，结果共享去重）。
- **教材目录树触控目标豁免**：156 章目录树不适用 43.5px，审计中豁免并注明；主操作全部达标。
- **旧 CSS 暂留**：旧 `.top-shell/.item-card/.audience-*` 等类随旧视图停用，保留在 styles.css 待下轮清理（见剩余项）。
