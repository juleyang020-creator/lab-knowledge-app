## ③ 病种关联库

- `scripts/build-diseases.ts` 从 catalog.json 手册条目「临床意义」字段抽取：**290 个病种、483 条关联、238 个项目被覆盖**；每条关联 = 项目编号 + 方向（升高/降低/其他）+ 原文短引文（≤240 字）+ 手册行号。契约与校验在 `src/domain/disease.ts`。
- 抽取原则（保守，宁可漏抽不造词）：逗号分段、方向按各小句触发词定、延续小句继承方向；共用后缀并列（肝、胆及骨骼疾病）不展开；括号内举例拆开抽；含数字/判断动词/评估类字样的片段拒收；病名后缀清单+白名单把关；异体（综合征/综合症、机能/功能）照录不合并。产出后全部 290 个病名经人工过目，清除了「亢进」「抗癌」「也可存在于小细胞肺癌」类坏词。
- 红线：病名是索引标签；卡片内容只有原文短引文，不写模型解读；页面明示不构成诊断或选检建议。
- 界面：`/#/diseases` 列表（筛选、关联数徽标、方向计数）与 `/#/diseases/:id` 详情（按方向分组、项目链接、手册原文跳转）；加载失败明确提示 `pnpm diseases:build`，不静默空白。
- 校验：`validateDiseases` 逐字核对引文与行号、项目存在性、病名唯一，已接入 `pnpm content:check`。
